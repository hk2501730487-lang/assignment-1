# Daily Calorie Meter

A simple web application for tracking daily calorie intake and monitoring progress toward a daily calorie goal.

## Features

* Add food items and their calorie values
* Track total calories consumed
* Set and monitor a daily calorie target
* View remaining calories for the day
* Simple and responsive interface
* Easy-to-use calorie tracking workflow

## How It Works

```text
Add Food
   ↓
Enter Calories
   ↓
Calories Added to Daily Total
   ↓
Compare With Daily Goal
   ↓
Track Remaining Calories
```
